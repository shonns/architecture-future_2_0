Барнацкий Е.А.: Технический радар для компании «Будущее 2.0»

  • ADOPT: Технологии и практики, которые стоит внедрять сейчас.
  • TRIAL Технологии, которые стоит пробовать на пилотных проектах.
  • ASSESS: Нужно изучать и оценивать для будущего внедрения.
  • HOLD: Технологии, которые не рекомендуется использовать для новых проектов. Технологии, в которые мы считаем, что не стоит (пока) инвестировать.
